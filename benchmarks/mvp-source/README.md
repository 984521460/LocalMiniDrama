# MVP benchmark source

This directory is the single source pack for the end-to-end MVP benchmark. Later narrative, character, workflow, H3, TTS, export, and review evidence must identify the same `sourceId` and `contentSha256` instead of substituting unrelated fixtures.

Run `npm run benchmark:source:check` from the repository root to verify the source bytes, rights statement, selected story range, and explicit encoding-choice probe.

The pack contains text and metadata only. It contains no credential, user data, model, voice, image, music, or generated media.
